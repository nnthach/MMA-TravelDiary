# 📸 Travel Diary – Mini React Native & ExpressJS Project

Travel Diary is a small practice project built to get familiar with **React Native (Expo)** and **ExpressJS**.  
It’s a simple mobile app where users can share their travel moments by posting photos, creating a lightweight social-style travel diary.

Although this is a beginner-friendly project, it demonstrates the full workflow of building a mobile app with a custom backend API.

---

## 🚀 Tech Stack

### **Frontend**

- **React Native (Expo)**
- Firebase Storage
- Axios
- Modern UI components (custom/lightweight)

### **Backend**

- **ExpressJS**
- RESTful API structure
- MongoDB (Mongoose)

---

## 📁 Repositories

- **Backend API:** https://github.com/nnthach/MMA-TravelDiary-API
- **Mobile App (Frontend):** https://github.com/nnthach/MMA-TravelDiary

## ✨ Features

- Create and share travel posts with images
- View posts from other users
- Simple and clean UI
- Practice setup for full-stack mobile development

This project is mainly for learning and having fun with React Native & ExpressJS — no pressure, just exploring and building. 😄
